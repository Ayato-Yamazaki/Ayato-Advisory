# Ayato Advisory — GitHub Pages

Upload every file and folder in this ZIP to the root of `Ayato-Yamazaki/Ayato-Advisory`.

Then open **Settings → Pages** in GitHub and set:

- Source: **Deploy from a branch**
- Branch: **main**
- Folder: **/(root)**

Expected public URL:

`https://Ayato-Yamazaki.github.io/Ayato-Advisory/`

Included:
- `index.html`
- `about/index.html`
- `careers/index.html`
- `assets/styles.css`
- `robots.txt`
- `sitemap.xml`
- `.nojekyll`

The ONLINE LESSON photo is loaded from Unsplash at runtime.
